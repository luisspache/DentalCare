🦷 DentalCare Pro - Sistema Odontológico Universal
O DentalCare Pro é uma aplicação web completa (Single Page Application - SPA), responsiva e de alta performance desenvolvida para a gestão integral de clínicas e consultórios odontológicos. O sistema funciona diretamente no navegador, utilizando o LocalStorage para persistência de dados local de forma gratuita e sem necessidade de configuração de servidores.

📱 Responsividade e Acesso Mobile
O sistema foi desenhado para se adaptar perfeitamente a qualquer tamanho de ecrã:

Telemóveis (iOS / Android): Navegação simplificada por menus colapsáveis, formulários ajustados para toque e visualização otimizada do odontograma.

Tablets e Computadores: Painel executivo com visualização de relatórios em tempo real, tabelas de dados expandidas e atalhos rápidos.

🚀 Principais Funcionalidades
1. 🔐 Autenticação e Perfis de Acesso
Controle de Perfil:

Administrador: Acesso ilimitado a todas as funções, relatórios financeiros, gestão do corpo clínico, controlo de stock e manutenção do banco de dados.

Dentista Assistente: Interface focada na área clínica (Prontuário, Odontograma, Agenda, Receitas e Exames), mantendo abas financeiras e administrativas ocultas e protegidas.

Fluxo Seguro: Verificação de existência de conta e modal de Recuperação de Senha ("Esqueceu a senha?") integrado.

2. 🦷 Odontograma FDI Interativo
Alternância de Dentição: Suporte completo a Dentes Permanentes e Decíduos (Infantis).

Mapeamento de Faces Dentárias: Seleção gráfica das faces (Vestibular, Lingual/Palatina, Mesial, Distal, Oclusal/Incisal).

Histórico Clínico: Registo imediato de tratamentos e procedimentos associados ao dentista autenticado.

3. 📅 Agenda Inteligente e Notificações
Gestão de consultas por status (Agendado, Confirmado, Em Atendimento, Concluído, Cancelado).

Botão de Confirmação via WhatsApp Direct para envio de lembretes ao paciente com apenas um clique.

4. 📄 Gerador de Documentos e Receitas
Emissão rápida de Atestados Médicos, Receituários, Termos de Consentimento (TCLE) e Recibos.

Layout otimizado para Impressão / Exportação em PDF.

5. 📊 Módulos de Gestão Integrada
Financeiro & Comissões: Cálculo automático de faturamento, fluxo de caixa e comissões dos dentistas.

Controlo de Stock: Alertas visuais para itens com quantidade abaixo do nível crítico.

Corpo Clínico: Gestão e cadastro de profissionais com verificação de CRO e especialidades.

🛠️ Tecnologias Utilizadas
HTML5 & JavaScript (ES6+ Vanilla): Arquitetura rápida e sem dependências complexas de compiladores.

Tailwind CSS: Estilização moderna e utilitária 100% responsiva.

FontAwesome 6: Iconografia vetorial médica e administrativa.

Chart.js: Gráficos interativos para análise financeira.
