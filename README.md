# 🦷 DentalCare Pro - Sistema Odontológico Universal

Sistema web completo e responsivo para gestão de clínicas odontológicas, desenvolvido em HTML5, Tailwind CSS e JavaScript (Vanilla).

## 🚀 Recursos
- **Níveis de Acesso:** Administrador e Dentista Assistente.
- **Prontuário & Odontograma FDI:** Dentição Permanente e Decídua com seleção de faces dentárias.
- **Agenda Inteligente:** Agendamentos e confirmação via WhatsApp Direct.
- **Documentos & Receituários:** Emissão de Atestados, Receitas e Termos (prontos para impressão/PDF).
- **Gestão Integrada:** Financeiro, Comissão de Dentistas, Controle de Estoque e Próteses.
- **Persistência de Dados:** Armazenamento local (`LocalStorage`) com exportação e importação de backups JSON.

## 🛠️ Tecnologias Utilizadas
- HTML5 & JavaScript (ES6+)
- Tailwind CSS & FontAwesome Icons
- Chart.js
